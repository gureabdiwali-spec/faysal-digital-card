CONTENTS
- index.html: responsive digital contact page
- gadano-logo.png: emblem cropped from the supplied business card
- faysal-moumin.vcf: contact file downloaded by the Save Contact button
- whatsapp-qr.png: temporary QR that opens a WhatsApp chat with a suggested introduction

IMPORTANT: the WhatsApp QR is a fallback, not the final digital-card QR.
To make the page and Save Contact button work online, upload all three page assets
(index.html, gadano-logo.png, faysal-moumin.vcf) together to a static hosting service.
Keep the filenames and folder structure intact. Then generate a new QR code pointing
to the published page URL (the URL must be HTTPS and publicly accessible).

Suggested no-code hosting: Netlify Drop (https://app.netlify.com/drop).
Upload the unzipped folder contents/folder, then test the published URL on a second phone.
A free host may provide a random subdomain; use a custom domain only if you later arrange one.
